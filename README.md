📊 Food Delivery App Data Analysis using Python

This project analyzes a food delivery dataset to uncover insights about delivery performance, customer satisfaction, and operational efficiency. Using Python libraries like Pandas, NumPy, and Matplotlib/Seaborn, the project explores how factors such as delivery time, distance, order value, city, delivery partner, and day of the week impact overall customer experience.

Key analysis performed includes:

Average delivery time across different cities

Relationship between delivery distance and delivery time

Impact of delivery speed on customer ratings

Performance comparison of delivery partners

Customer experience across cities

Effect of high-value orders on ratings

Identifying the day with the worst delivery experience

The project demonstrates practical data cleaning, exploratory data analysis (EDA), and visualization techniques to derive meaningful business insights for improving food delivery services.
The project is very small and can be used for reference (Can be a good idea to start new projects by applying the ideas)
